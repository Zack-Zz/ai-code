# 多插件仓库改造验证记录（2026-10-07）

结论：仓库改造已实现，独立审查发现已修复，等待用户 Review。改动保持未提交；
本轮未进行宿主安装、外部发布或真实宿主会话验收。

## 变更与实际范围

- 现有 workflow 的源码、测试、验收材料与文档迁入
  `plugins/ai-code-workflow/`，保留插件 ID、候选版本 2.0.0、工作流命令和
  `.ai-workflow` 状态语义。
- `catalog.json` 只登记目录。公共 `tooling/plugin_tool.py` 支持独立选择、
  源校验、按声明宿主构建和基于可信源码的包检查，不加载 workflow 模块。
- 两端市场聚合生成，名称为 `ai-code-local`；各插件独立版本与 ZIP，ZIP
  包含自身资源和单插件市场。根发行索引为 schema 2。
- 统一门禁按登记目录发现测试，CI 校验与构建所有登记插件。接入要求见
  [作者指南](../plugin-authoring.md)，契约见[改造规格](../design/2026-10-07-multi-plugin-design.md)。

目前正式登记的产品仍只有 AI Code Workflow。多插件能力由临时第二插件
fixture 验证，覆盖不同版本、不同宿主、独立选择、不要求工作流资源和兄弟
插件哈希隔离；本轮没有新增第二个正式产品或 MCP 运行集成。

## TDD 与独立审查

新增行为先记录有效失败，再实现并跑绿。独立审查发现的技能引用闭包缺失、
生成目标父子重叠已修复，审查员原始 fixture 复验均被校验器拒绝。其他
回归包括输出别名进入源码、ZIP 混入兄弟插件、特殊文件、市场源路径及
原生策略、严格 schema 类型、篡改后自重算哈希、空组和失败后继续运行。

本轮快照与 RED/GREEN、完整命令日志保存在当前机器的
`/private/tmp/ai-code-multiplugin-20261007/`。原 dist 已完整保存在该目录
`previous-dist/`，源码基线为 `baseline.tar.gz`；临时目录不是正式发行依赖。

## 剩余边界

原生加载、技能触发、多个插件共同安装后的选择与冲突、Reviewer 权限和
MCP 启动/认证/调用仍需相应插件、宿主和模型组合的真实会话证据。
当前结果只覆盖仓库工具、发行完整性和实际包内管理命令，不更新
[历史宿主支持结论](../../plugins/ai-code-workflow/docs/support-matrix.md)。

旧根路径的工作流入口已迁移，外部脚本需按插件文档更新；本轮未修改外部
脚本、全局配置或宿主缓存。包检查须使用与该候选产物对应的可信源码，
完整性通过不等于作者身份认证。commit、push、tag、merge、PR 仍需单独授权。
