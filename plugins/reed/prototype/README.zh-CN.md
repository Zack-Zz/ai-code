# Reed 交互 Demo

[English](README.md) | 简体中文

**Many agents. One flow.**

Reed 本地工作流工作台的前端原型。沿用用户确认的原生浅色调性与平衡版 R，支持系统／浅色／深色。

## 体验范围

- 我的看板：待办、进行中、评审中、完成；卡片保留工作流阶段，以及文档、会话和分支入口。支持拖拽和「移动」入口。点击卡片以右侧抽屉查看详情，保留看板、筛选和滚动位置；文档、会话预览也保留上下文。提交评审和完成前检查产出与流程条件，并明确确认准确版本。
- 任务：列表与阶段看板、搜索、来源与阶段筛选、新建、导入、暂停、归档和恢复。
- 工作流：需求 → 设计 → 开发 → 验证，人工验收、反馈修改、重试与返工，保留历史。
- 文档：阅读、修改、版本回看和 Markdown 下载。返工与修改反馈将旧产出标为过期，生成或保存新版本后才能再次评审。
- 关联：在任务、会话和分支视角间切换，查看关联历史与工作区上下文。
- 开发准备：选择模拟宿主、准备隔离工作区、验证会话目录，然后开始。
- 连接器：按官方 CLI 接入方案配置多个独立命名的云效连接，支持中心版与 Region 版。完整体验身份、分步检测、项目／类型范围和状态映射，停用后保留历史；每个实体记录自身来源。
- 同步：模拟待同步、远端修改、冲突解决，以及必须先核查的未知结果。

可以从 **REQ-1042 → 确认设计** 开始体验开发准备。「我的看板」按推进状态分组，任务页的看板继续按阶段分组。四端选项和外部执行结果均清楚标为模拟。

## 配置演示来源

点击侧栏底部 **连接器**；窄窗口使用顶部插头按钮。在当前任务或看板上弹出连接器列表。云效提供 **自定义配置** 和 **发现本机配置** 两条路径；**已添加的连接** 可直接编辑，**管理全部** 才进入完整管理页。

本机发现提供中心版、Region 版和缺字段三个模拟候选，自动生成可编辑、默认仅拉取的草稿，明确保存后才添加连接。同一身份已有连接时直接编辑；缺少组织 ID 需补齐。未发现配置或模拟本地服务不可用时，可重试或转自定义配置。不扫描环境、文件、CLI 或真实凭据，保存时只记录必要的配置来处说明。

两条路径都进入四步配置：

1. **连接身份**：填写唯一连接名，选择中心版／Region 版。中心版填写组织 ID，Region 版填写 HTTPS 实例地址。选择模拟账号、PAT 权限场景与 CLI 环境；没有真实 Token 输入。
2. **连接检测**：依次模拟 CLI／插件、PAT、组织／实例身份和项目读取。前置失败则后续不执行；可保存待处理配置，或返回修正。
3. **同步范围**：选择模拟项目、工作项类型、仅拉取／双向同步。
4. **状态映射**：按项目与类型，把 Reed 进展映射到云效状态 ID。可采用建议后调整，检查完整配置再保存。双向配置要求映射完整且完成状态对应终态；只有读取权限时仍可保存并导入，回写保持禁用。

已有连接的 **检测连接** 会重跑各项并展示结果。令牌过期、CLI 不可用、无项目权限均为明确的本地模拟场景；权限和映射改动使对应检测失效。正式接入计划由本地服务与系统凭据库负责，本前端不执行 CLI、不访问云效网络。

导入时明确选择连接和项目，按连接、项目与外部编号去重。来源详情展示版本、账号、项目、已记录的工作项类型、Connector ID 和外部编号。不同连接的相同外部编号会建立独立任务。改名或停用保留原身份与数据；早期缓存仍保留历史／未知来源。

同步窗口展示状态映射预览，并把准确状态 ID 保存为模拟回读快照，不改变本地阶段或验收。项目移出范围、工作项类型切换后，范围外任务保留来源和本地操作，但不能继续同步。

所有单选下拉框使用统一的 Reed 菜单样式，适配浅色、深色与系统外观。长列表支持搜索、来源分组、云效官方图标与连接说明。可用 ↑／↓ 移动、Enter 确认、Esc 关闭、Tab 继续；弹窗内先关闭菜单，保留原弹窗。官方图标及出处见[素材来源](public/assets/yunxiao-mark-source.txt)。

## 个人设置

从左下角 **设置** 进入；窄窗口使用导航中的齿轮图标。外观支持系统／浅色／深色，界面语言支持简体中文／English，偏好保存在当前浏览器。切换语言会更新菜单、弹窗和提示等界面文案；任务内容、文档正文、连接名称和云效原始状态值保留原文，筛选与已保存表单草稿保持。**设置 → 关于 Reed** 统一放置演示说明、数据导出与重置，侧栏不再单独展示「交互预览」。

## 本地数据与边界

本 Demo 将当前个人工作台内的本地任务作为个人集合，尚未接入真实团队的负责人和分配筛选。任务和外观保存在当前浏览器的本地存储，表单草稿使用会话存储；清理浏览器数据会移除这些内容。尚未实现架构中的 SQLite 本地服务、凭据管理与备份。关于窗口可以导出 JSON 快照，并且只重置本 Demo 的数据。

未连接真实云效 API、MCP、Agent 执行、原生会话跳转、Git 分支或 worktree 操作。Demo 不读取本地仓库、不持有凭据、不修改外部系统，尚未注册插件市场。

## 开发与验证

使用 Node.js 22 或更高版本。通过 `npm ci` 安装依赖；运行 `npm run dev -- --host 127.0.0.1 --port 4173 --strictPort` 启动预览。

- `npm test`：工作流状态与数据完整性测试。
- `npm run build`：前端生产构建，以及保留的可选托管脚手架。
- `npm run test:sites`：构建后的本地脚手架测试，不会发布。

仓库统一门禁不会发现未注册的原型，需单独执行其测试。React 渲染由生产构建与浏览器走查检查；根 ESLint 检查原型的 JavaScript 模块，当前配置未覆盖 JSX。

参见[视觉验收](design-qa.md)、[验证记录](verification.md)与[交互规格](../docs/design/2026-10-28-reed-interaction-design.md)。浏览器截图保存在被 Git 忽略的 `.evidence/`，仅为本地验收材料。
