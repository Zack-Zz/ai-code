# CodeVow 1.0.1：发行收尾与三宿主确定性验收

用户已确认完成发行一致性和验收工具链两项；真实宿主会话、人工语义验收收口
及轻量化行为调整不属于本轮。

## 方案与边界

- product.json 的版本升为 1.0.1；身份、宿主和资源白名单仍由该文件维护。
- 保留已有未提交的 Claude 证据输入修复，闭字段数据结构和退出码语义不变。
- A23/A24/A25 prepare 从插件声明读取宿主，为全部声明宿主生成独立包；
  不增加 prepare 命令选项或模型运行器。
- collect 继续按真实输入 manifest.host 绑定包。A23/A24 grade 执行绑定包的
  文件暂存、更新、移除、冲突及恢复检查，不执行宿主原生安装。
- A25 检查全部声明宿主的包、身份、版本、来源及共同资源哈希；宿主清单和
  生成的界面/Agent 资源按适配声明处理，不能按任意路径排除不一致。
- A25 使用校验后的源码输入快照，并将其来源哈希绑定场景发行记录；生成
  Reviewer 的完整内容必须与该快照的模板和共同职责正文合成结果完全相符。
- grader_version 升为 1.2.0。包内 CLI 执行证据不替代公共工具从可信源码
  重建闭包的包检查，两层验证分别保留。
- release acceptance 的三个槽继续为 null，真实宿主能力继续为 unverified。
  旧两端材料保留原日期、哈希和范围，不晋升为本轮三端结果。

## 实施与完成条件

1. 对样例宿主覆盖、三端 prepare→collect→grade 和共享资源漂移先运行有效
   失败测试，再最小实现并跑绿；既有身份/材料/基线保护继续通过。
2. 更新当前导航与发行说明，保留历史版本及原验证数据。
3. 构建到仓库外的空目录，独立检查三端包；仅替换既有生成产物并同步市场。
4. npm test、lint、源码校验、可信包检查、可复现发行比较、marketplace
   sync --check、draft release prepare/verify 和 git diff --check 全部通过。

完成后保留未提交改动供用户 Review。版本记录、测试通过和本设计均不授权
commit、push、tag、PR、安装或外部发布。
