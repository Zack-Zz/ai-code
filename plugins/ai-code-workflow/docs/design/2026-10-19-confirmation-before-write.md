## 目标与改动

用户原文：“devops增加一个初始化产品线应用端的入口，你看下怎么处理？”
没有覆盖当前需求的既有开发授权时，先调查并给方案。默认 `collaborative` 下，
即使明确提出开发需求，也不能把需求本身或助手展示方案当作用户确认。

- 将首次写入检查收拢到 workflow 共同授权入口：区分只读咨询、未确认开发、
  已确认范围与 continuous 范围；等待真实用户回复或宿主原生计划确认。
- 确认范围覆盖测试、诊断、配置、文档、数据和任务/计划文件，以及委派写入。
  已确认范围内复用授权，普通后续问句不触发重复确认。
- 双语使用指南与随包 README 明确 ZCode 当前 Workspace 根 `AGENTS.md` 入口，
  用户主动合并，区分 CodeVow 流程模式与宿主原生执行模式。
- 保留现有策略与任务 Schema、管理工具接口和版本；不新增授权标记或运行时拦截。
